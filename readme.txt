二、研究范围与主线
权重空间编程及相关权重学习／编辑／合并；零阶优化；表征与激活引导；神经架构搜索；具身模型和机器人闭环控制。
比较主线是干预对象、提案机制、可用信息及验证协议；重点区分准备、搜索、部署和独立验证成本。保留失败、能力回退、迁移限制和副作用，避免跨任务、硬件或单位直接排名。

三、文献进度
16 组查询得到 528 条去重候选，结合 77 条种子／定向补检记录得到 590 条唯一候选，最终选择 200 篇。
按主组计数：权重空间与编辑 50、零阶优化 35、表征引导 45、NAS 45、具身控制 25。每篇都有中文机制笔记、成本／局限笔记、原始链接和核验状态。
62 篇核验全文相关章节，138 篇完成元数据与摘要筛选；不是 200 篇全文逐页精读。叙述性选择不代表穷尽检索或双人独立筛选。原作者 Sparks 博客作为补充背景，不计入 200 篇。
