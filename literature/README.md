# 200 篇文献及证据记录

检索／核验日期：2026-11-09。正文编号 [1]-[200] 与以下文件一致。

- `corpus-200.csv`：编号、完整作者、题名、分组、原始链接、版本、核验深度、中文机制和成本／局限笔记。
- `references-200.json`：相同的可编程元数据，供 PDF 构建使用；不包含第三方摘要。
- `references-200.bib`：BibTeX，保留原始 arXiv 标识符和 URL。
- `search-log.csv`：16 组查询的精确字段、排序、上限和结果量；另列 77 条定向种子记录入口。
- `screening-log.csv`：590 条候选的纳入、排除或未选状态；不等于 590 篇全文审查。
- `evidence-ledger.csv`：主要定量／机制结论的原文位置和适用边界。
- `corpus-summary.json`：计数与协议摘要。

## 数量与版本

查询结果 528 条唯一记录，与 77 条种子／补检记录合并后为 590 条，选入 200 篇。以 arXiv 标识符合并版本，并检查选入题名无规范化重复。主组为 W 50、Z 35、S 45、N 45、E 25；交叉方法只在主组计一次，不表示分类互斥。

`first_published` 是 arXiv 初次发表时间，`metadata_updated` / `metadata_version` 是本次取得的元数据版本；`inspected_version_url` 若存在，优先表示前期实际核验的版本。参考文献通常采用预印本初次年份；NAS 综述 [131] 链接 JMLR 2019 正式版本，保留其 arXiv 标识符供去重。

## 核验深度

62 篇检查了全文相关方法、结果或限制段落，138 篇以题名、元数据和摘要筛选。前者不是全篇逐页精读或独立复现，后者只支持本文的机制与范围定位。关键数字使用单独证据表中的原文，不把摘要报告的领先幅度合并排名。

三个定向种子因标识符错配剔除；`2502.06851` 因摘要明确声明为 AI 自动生成演示而未纳入实质研究综述。其他未选候选是代表性选择结果，不表示研究质量差。

原作者 Sparks 博客作为补充背景，未计入 200 篇。文献 [47] 明确标记技术猜想，不能当作已实验验证的 WSP 图像复原方法。近年预印本不在这里被默认标记为同行评审论文。

这些记录支持可追溯的叙述性综述，不宣称穷尽检索、双人筛选或元分析。逐篇中文笔记为本项目归纳；第三方论文全文和完整摘要不在仓库重新分发。
