## 主要发现

1. 现稿的大多数抽查事实在所查原文段落得到支持。此次不是对全部 200 篇引用的认证。
2. 动态干预、激活与权重操作、权重生成与 NAS 的联系均已出现在已有综述中；原稿没有明确宣称这些是首创，本轮进一步划清贡献边界。
3. 候选、选择决策与最终产物需要分别记录，避免引用被弃用候选作为最终系统结果。
4. 成本公式需要按资源定义聚合：峰值显存不能随阶段求和，并行墙钟时间不能当作 GPU 时间相加。
5. Steer2Edit [120] 在原矩阵中仅为摘要筛选；此次读到 v3 §3.1 并复核编辑形式，但没有覆盖全部实验。保留原 corpus 的历史状态，通过本轮表补充，而不静默改写既有 62/138 计数。
